# Armaghan Portfolio

A React + Vite rebuild of the [Framer portfolio](https://armaghanhasan.framer.website/).

## Stack

- React 19
- Vite 7
- TypeScript
- Tailwind CSS
- React Router
- Framer Motion
- Lenis (smooth scroll)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run preview` — preview production build
- `npm run lint` — run ESLint

## Pages

- `/` — Home navigation
- `/about` — About
- `/portfolio` — Project listing
- `/portfolio/:slug` — Project case studies
- `/contact` — Contact form
